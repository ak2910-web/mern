## Practical No. 1

## Practical 1B - Create a simple Node.js file and run it using terminal.

**Aim:** - Environmental Setup and JavaScripts Basics.

### b) Create a simple Node.js file and run it using terminal.

#### 1. Create a folder named MERN_Practicals.

#### 2. Open the folder in VS Code.

#### 3. Create a file named app.js.

#### 4. Add JavaScript code to `app.js`.

```bash
console.log("Welcome to Node.js");
```

`console.log()` prints output in the terminal.

#### 5. Open the terminal.

#### 6. Run the program using:

```bash
node app.js
```

#### 7. Output

```text
Welcome to Node.js
```

Every Node.js file should have a `.js` extension.
